# OBRA360
Aplicativo Android offline-first para uso prático no canteiro.
Stack: Kotlin, Jetpack Compose, Material 3, MVVM, StateFlow e Room.
Módulos: Dashboard, Obras, progresso, tarefas, diário, checklist e calculadoras de concreto, argamassa, blocos e pintura.
Ambiente: CodeAssist by Tyron 3.19 ou Android Studio, JDK 17, AGP 8.7.3, compileSdk 35.
Build: ./gradlew :app:assembleDebug
